◈ About SCLM

SCLM — Star Citizen Loot Manager is a free, non-commercial fan-made tool created by and for the Star Citizen community to fairly distribute loot and cargo among crew members.

This project was created with the assistance of AI (Claude by Anthropic) and is shared freely with the community. It is not affiliated with or endorsed by Cloud Imperium Games.

Use of the Star Citizen Fankit assets on this site is in accordance with the CIG Fankit & Fandom FAQ. This site is non-commercial and no fees are charged for its use.

◈ Data Sources & Credits

Ship component data is provided by UEX Corp via their public API at uexcorp.space. SCLM is not affiliated with UEX Corp. All UEX data is subject to their own terms of service.

Event imports use data exported from Raid-Helper (raid-helper.dev). SCLM is not affiliated with Raid-Helper.

◈ Data & Privacy

SCLM does not transmit or sell any user data to third parties.
All event and participant data is stored in the database of the server hosting this instance of SCLM. If you are using a publicly hosted instance, your data is stored on that server operator's infrastructure. For full control over your data, you can self-host SCLM using the provided Docker image.

External network requests made by this application are limited to: the UEX Corp API (triggered manually by an admin for component data import) and Raid-Helper CDN (for loading event banner images only).
